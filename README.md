# ⚡️ Phasor Precision

A modern, lightweight desktop application built with **Electron** to perform quick conversions between **Phasor (Polar)** and **Rectangular** coordinates. 

This tool was designed for Electrical Engineering students and professionals who need a fast, reliable, and visually pleasing way to handle complex numbers in circuit analysis.



## ✨ Features

- **Bidirectional Conversion:** - Rectangular ($R + jX$) to Polar ($M ∠ θ°$).
  - Polar ($M ∠ θ°$) to Rectangular ($R + jX$).
- **Modern UI:** Sleek "Glassmorphism" design with a dark theme.
- **Engineering Accuracy:** Results rounded to 3 decimal places for better precision in impedance and power calculations.
- **Cross-Platform:** Compatible with Windows, macOS, and Linux.
